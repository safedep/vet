# vet v2.2.0

This page lists the changes of v2.2.0 that a user sees. The release is not out yet.

## What is new

- **Reach.** Each vulnerability finding of a directory or a git clone says how far the code of the
  project reaches the vulnerable package: `imported`, `unused` or `unknown` with a cause. vet never
  shows `unknown` as safe. `--reach off|import|function` and `plugins.codeusage.options.reach` set
  the level. The JSON report has `reach` on each such finding and on the scan header.
- **Code analysis is on by default.** A default scan of a directory now reads the source files. It
  needs a vet build with CGO, and a static build skips it with no diagnostic. `cache.db` keeps the
  index of each file, so a second scan parses only the changed files. vet parses the code while it
  waits for SafeDep Insights. `plugins.codeusage.options.budget` bounds the time, 5m by default.
  `plugins.codeusage.enabled: false` turns off all code analysis.
- **The GitHub Action keeps the vet cache.** The action restores the vet cache directory before
  the scan and saves it after. The `cache` input turns this off.
